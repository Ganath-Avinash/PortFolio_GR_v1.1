# Portfolio Web

## What's this?
A modern, interactive, and visually engaging personal portfolio website. It features 3D elements, smooth animations, and a sleek user interface designed to showcase projects, skills, and professional experience in an immersive way.

## What is it for?
This portfolio serves as a central hub for professional branding. It is designed to:
- **Showcase Projects**: Display software development projects, technical skills, and certifications.
- **Tell a Story**: Provide a timeline of education, work experience, and achievements.
- **Engage Visitors**: Deliver a dynamic, interactive experience for visitors, clients, and recruiters using 3D physics and animations.
- **Demonstrate Proficiency**: Act as a live demonstration of proficiency in modern web development technologies.

## Tech Stacks Used
This project is built using a modern, performance-focused frontend tech stack:

### Framework & Core
- **[Next.js](https://nextjs.org)** - The React framework for the web (App Router).
- **[React](https://react.dev)** (v19) - Core library for building user interfaces.
- **TypeScript** - Strongly typed programming language building on JavaScript.

### 3D & Graphics
- **[Three.js](https://threejs.org)** & **[@react-three/fiber](https://docs.pmnd.rs/react-three-fiber)** - For rendering interactive 3D graphics.
- **[@react-three/drei](https://github.com/pmndrs/drei)** - Useful helpers and abstractions for React Three Fiber.
- **[@react-three/rapier](https://github.com/pmndrs/react-three-rapier)** - 3D physics engine for interactive elements.

### Styling & UI
- **[Tailwind CSS](https://tailwindcss.com)** (v4) - Utility-first CSS framework for rapid UI development.
- **[shadcn/ui](https://ui.shadcn.com)** & **[Radix UI](https://www.radix-ui.com)** - Accessible, headless, and customizable UI components.
- **[React Bits](https://reactbits.dev/)** - Used for beautiful, ready-to-use, and highly customizable animated React components.
- **[next-themes](https://github.com/pacocoursey/next-themes)** - For easy dark/light mode switching.

### Animations
- **[Framer Motion](https://www.framer.com/motion/)** - Powerful animation library for seamless React transitions.
- **[GSAP](https://gsap.com/)** - Professional-grade animation library for complex timelines and scroll-triggered effects.

### Icons & Extras
- **[Lucide React](https://lucide.dev)** & **[React Icons](https://react-icons.github.io/react-icons/)** - Comprehensive icon libraries.
- **[react-github-calendar](https://github.com/grubersjoe/react-github-calendar)** - Component to visualize GitHub contribution graphs.
